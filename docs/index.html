SimpleResizer

Лёгкое приложение для Windows, которое меняет размер изображений и сразу показывает результат рядом с оригиналом.

Сравнение «до / после»

Две панели рядом: исходное изображение и результат обработки.

Масштабирование просмотра

Изображения в обеих панелях можно приближать и двигать, чтобы рассмотреть детали.

Популярные форматы

Открывает файлы JPG, JPEG, PNG и TIF через стандартный диалог выбора файла.

На базе OpenCV

Обработка изображений выполняется библиотекой OpenCV (OpenCvSharp).
